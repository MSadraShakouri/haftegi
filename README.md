# هفتگی

یک برنامه‌ساز هفتگی ساده و بدون نیاز به نصب که کاملاً در مرورگر اجرا می‌شود.

## امکانات

- **جدول تعاملی** — روی هر خانه کلیک کنید و تایپ کنید. با تایپ، نام کلاس‌های قبلی به‌صورت خودکار پیشنهاد می‌شوند.
- **۸ پالت رنگ** — پاستل، وایبرنت، نئون، تیره، مات، رترو، جواهر و آب‌نباتی. هر پالت شامل ۱۰ رنگ متمایز است.
- **پشتیبانی هوشمند از فارسی** — حروف عربی `ك` و `ي` به‌طور خودکار به `ک` و `ی` فارسی تبدیل می‌شوند. جستجو نیز `آ`، `ا`، `أ` و `إ` را یکسان در نظر می‌گیرد.
- **رنگ متن خودکار** — رنگ متن هر خانه از روی رنگ پس‌زمینه محاسبه می‌شود (مثلاً متن سبز تیره روی پس‌زمینه سبز روشن).
- **انتخاب رنگ برای هر کلاس** — با کلیک روی دایره رنگی کنار هر کلاس، می‌توانید رنگ آن را تغییر دهید. هر رنگ فقط به یک کلاس تعلق دارد.
- **ستون‌های قابل تنظیم** — سه قالب آماده (تایم، ساعت ۲۴ ساعته، ساعت ۱۲ ساعته) یا ستون‌های کاملاً دلخواه. امکان افزودن و حذف ستون بدون محدودیت.
- **تغییر نام گروهی** — با ویرایش نام یک کلاس در نوار کناری، تمام خانه‌های مرتبط به‌صورت خودکار به‌روزرسانی می‌شوند. مناسب برای اصلاح سریع اشتباهات تایپی.
- **رنگ‌بندی تصادفی** — با یک کلیک، رنگ‌ها بین کلاس‌ها جابه‌جا می‌شوند.
- **دانلود تصویر JPG** — دریافت خروجی تمیز از برنامه، بدون هیچ عنصر اضافه.
- **کاملاً واکنش‌گرا** — روی موبایل، تبلت و کامپیوتر به‌خوبی کار می‌کند.

## نحوه استفاده

۱. فایل `index.html` را باز کنید یا از [نسخه آنلاین](https://YOUR_USERNAME.github.io/haftegi/) استفاده کنید.

۲. نام کلاس‌ها را در جدول وارد کنید. با تایپ کردن، نام‌های مشابه پیشنهاد می‌شوند.

۳. از نوار کناری، پالت رنگ دلخواه را انتخاب کنید.

۴. برای تغییر رنگ یک کلاس خاص، روی دایره رنگی کنار نام آن کلیک کنید.

۵. برای دریافت خروجی، روی «دانلود تصویر JPG» بزنید.

## اجرای محلی

فقط فایل `index.html` را در مرورگر باز کنید. همین.

اگر می‌خواهید از طریق سرور محلی اجرا کنید:

```bash
# با Python
python -m http.server 8000

# یا با Node
npx serve
```

سپس در مرورگر به آدرس `http://localhost:8000` بروید.
